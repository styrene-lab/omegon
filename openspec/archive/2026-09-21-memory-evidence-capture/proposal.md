# Evidence-backed session memory formation

## Intent

Replace extraction from truncated first/last messages and count-only automatic
episodes with substantive, source-linked session evidence. Preserve useful work
when a long session compacts, ends, or is interrupted.

## Scope

Structured episodes, bounded checkpoints, durable extraction work, classified
candidates, retry identity, and shutdown recovery. Reuse canonical session/tool
evidence; do not build a competing transcript or persist private reasoning.

## Success criteria

- Mid-session decisions, corrections, failed attempts, and verification survive.
- Episodes identify goals, outcomes, unresolved work, and source handles.
- Extraction emits typed candidates rather than treating every line as Architecture.
- Restart resumes unprocessed committed evidence without duplicate memories.
