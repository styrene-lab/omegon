# Evidence-backed procedural memory

## Intent

Retain reusable workflows and environment gotchas with outcome evidence so later
sessions avoid repeated mistakes. Facts alone do not capture prerequisites,
execution sequence, failure conditions, and validation.

## Scope

Procedural candidates derived from episodes, applicability-aware retrieval,
outcome feedback, correction/retirement, and explicit promotion into the existing
skills ownership boundary. This change does not implement a second skills engine.

## Success criteria

- Failed attempts cannot be promoted as verified successful procedures.
- Procedures retain prerequisites, evidence, validation, and known failure conditions.
- Inapplicable procedures do not steer the current task.
- Existing skills remain inspectable and are not silently rewritten by learning.
